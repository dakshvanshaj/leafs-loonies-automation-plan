## What is already solved

Wagepoint calculates the deductions and connects to QuickBooks Online, 7shifts and Deputy ([Wagepoint](https://wagepoint.com/integrations), read 2026-11-05). I would not rebuild that. Sources disagree on whether it has a public API, so I would ask Wagepoint before relying on one. My work is around Wagepoint: clean hours in, checks before approval, and tying the result to the books.

## The steps

1. **Hours come in.** Use Time by Wagepoint, 7shifts or Deputy where they fit the client. Other clients get a simple form that goes to the system.
2. **Check the hours,** before they reach Wagepoint.
3. **Load Wagepoint.** Through an add-on or import. If neither works for a client, the admin enters the checked hours until there is a better way.
4. **Check the calculated pay.** Compare the pay run to recent runs, and recalculate sample lines from CRA's formulas as a second opinion.
5. **Send you one approval.** An email with totals, what changed since the last run, and every flag.
6. **You approve and run it.** The system records exactly what you approved. If any number changes afterward, the approval is cancelled and you see it again.
7. **Tie it back.** Stubs and reports come from Wagepoint. Its QuickBooks auto-sync, which I understand is off by default, posts the journal. The system then checks the journal against the pay run and the bank.

## Checks

A failed check here stops the step. My earlier work on Narada OS only warned, which is fine for stock advice and wrong for someone's pay.

| Check | If it fails |
|---|---|
| Hours fit the employee's schedule and recent pay runs | Run stops, reason shown |
| Pay rate, new hire or departure changed since the last run | Listed for your eye |
| Net pay swings far from recent runs | Listed for your eye |
| Sample pay lines recalculated from CRA's [T4127 formulas](https://www.canada.ca/en/revenue-agency/services/forms-publications/payroll/t4127-payroll-deductions-formulas.html) | Run stops, difference shown |
| Anything changed after you approved | Approval cancelled, you see it again |
| Posting journal in QuickBooks = pay run = bank withdrawal, allowing for Wagepoint's own fee, which does not export to QuickBooks (confirm in setup) | Flagged after the run |

Quebec is separate: CRA's payroll calculator excludes it ([CRA](https://www.canada.ca/en/revenue-agency/services/e-services/digital-services-businesses/payroll-deductions-online-calculator.html)). Any Quebec clients need their own check.

## What you still do by hand

- Approve and run every payroll
- Decide unusual pay, such as bonuses, leave and final pay
- Handle new hires and departures in Wagepoint
- The admin enters hours for any client with no import route
