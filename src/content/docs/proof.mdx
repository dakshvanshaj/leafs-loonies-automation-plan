From May to October 2026 I built Narada OS, an inventory and buying decisions platform for distributors. I built it alone, using Claude Code and Google Antigravity.

**The limits:** Narada has no customers, and it is not accounting software. I can't show you hours saved for a real business. You asked for that, and I don't have it. I also have no bookkeeping, payroll or tax experience, so I would rely on you for those rules.

## What carries over

| You need | What I built in Narada OS | Read about it |
|---|---|---|
| Wrong numbers flagged first | Checks on incoming data every night | [What Narada checks](https://naradaos.com/help/how/what-narada-checks/) |
| A person approves before anything goes out | Purchase orders are drafts; Narada never sends them | [Purchase Orders](https://naradaos.com/help/order/purchase-orders/) |
| A person can overrule the system | Change, skip or dismiss, with what sticks spelled out | [When you disagree](https://naradaos.com/help/start/when-you-disagree/) |
| AI that doesn't make up numbers | An assistant that answers from verified tools | [Ask Narada](https://naradaos.com/help/ask-narada/) |
| Docs a non-technical person can follow | The full help site | [naradaos.com/help](https://naradaos.com/help/) |

The code is private, so I can show you more on a screen share.
